# Labyrinth IPTV — Releases

Download builds of **Labyrinth IPTV** for desktop. This repository only hosts release
downloads and issue reports; the app's source code is not published here.

➡️ **[Latest release](https://github.com/labyrinth-apps/labyrinth-iptv-releases/releases/latest)** · [All releases](https://github.com/labyrinth-apps/labyrinth-iptv-releases/releases)

## Windows

### Portable (recommended)

1. Download `labyrinth-iptv-portable-v*.zip` from the latest release.
2. Extract it to any folder.
3. Run `labyrinth_iptv.exe`.

No installation and no admin rights needed. To update, download the new ZIP and replace the folder.

### MSIX installer

1. Download `labyrinth_iptv.msix` from the latest release.
2. Double-click it to install.

The MSIX package is self-signed, so Windows may show a security warning or ask you to
trust the certificate first. If that's a problem, use the portable version.

**Requirements:** Windows 10 or 11, 64-bit.

## macOS

1. Download `Labyrinth-IPTV-<version>-macOS.dmg` from the latest release.
2. Open it and drag **Labyrinth Streaming** into **Applications**.
3. Open it from Applications.

The app is signed and notarized by Apple, so it opens without security warnings.
To update, download the new DMG and replace the app in Applications.

**Requirements:** macOS 13.5 or later, Apple Silicon or Intel.

## Other platforms

- **Android / Android TV / Fire TV** — available via Google Play, or sideload the APK when one is attached to a release.
- **iOS** — available on the App Store.

## Getting started

Labyrinth IPTV is a player: it doesn't come with any channels or content. Sign in with
your own IPTV provider details (Xtream Codes login or an M3U playlist URL).

## Support

Found a bug or something not working? [Open an issue](https://github.com/labyrinth-apps/labyrinth-iptv-releases/issues/new)
and include:

- your platform and app version (shown in Settings)
- what you did and what happened
- a screenshot, if it helps

Please don't post your IPTV server address, username or password in an issue.
